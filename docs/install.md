## 💻 Instruções para Windows

1. Clique no botão azul acima para baixar o arquivo `.zip`.
2. Após o download, clique com o botão direito no arquivo e selecione **Extrair Tudo...**
3. Mova a pasta extraída para um local seguro no seu computador (como a pasta *Documentos*).
4. Entre na pasta e dê um duplo clique em `InternManager.exe`.

!!! tip "Dica: Crie um atalho"
    Para facilitar o uso diário, clique com o botão direito no arquivo `InternManager.exe`, vá em **Enviar para** e escolha **Área de trabalho (criar atalho)**.

---

## 🍎 Instruções para macOS

1. Clique no botão de download para Mac acima.
2. Dê um duplo clique no arquivo `.zip` baixado para extraí-lo.
3. Arraste o aplicativo `InternManager.app` para a sua pasta de **Aplicativos**.

!!! warning "Atenção: Segurança do macOS (Gatekeeper)"
    Na primeira vez que você for abrir o sistema, o Mac pode exibir um aviso de segurança. Para contornar isso (necessário apenas uma vez):
    
    1. Não dê duplo clique normal.
    2. Clique com o **botão direito** (ou segure `Control` e clique) no `InternManager.app`.
    3. Selecione **Abrir** no menu.
    4. Confirme clicando em **Abrir** novamente na caixa de diálogo que aparecer.

## 🔄 Como Atualizar o Sistema

Quando uma nova versão for lançada, você pode atualizar o sistema de forma segura **sem perder os dados cadastrados**. 

O Intern Manager Pro salva seu banco de dados em uma pasta protegida do sistema operacional, totalmente separada da pasta do aplicativo.

**Siga estes passos para atualizar:**

1. **Faça um Backup (Recomendado):** Abra a sua versão atual, vá no botão de *Configurações* (engrenagem) e clique em *Backup de Fotos* e *Exportar Excel*.
2. Exclua a pasta da versão antiga do seu computador (ou envie o `.app` para a lixeira no Mac).
3. Baixe a versão mais recente e extraia os arquivos normalmente.
4. Ao abrir a versão nova, o sistema reconhecerá seu banco de dados antigo automaticamente.

!!! info "Migração Automática"
    Se a nova versão contiver novos recursos (como novas tabelas e gráficos), o banco de dados será atualizado silenciosamente logo na primeira inicialização, mantendo todos os seus registros antigos perfeitamente intactos.
