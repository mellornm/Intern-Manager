⚠️ Leia antes de instalar

Como este é um software acadêmico independente (não pago certificados caros da Microsoft/Apple), o sistema pode emitir um alerta de segurança na primeira vez.

No Windows (Tela Azul)

Se aparecer a tela "O Windows protegeu o computador":

  1. Clique em Mais informações (texto pequeno).
  2. Clique no botão Executar assim mesmo.

No MacOS

Se aparecer um aviso que o desenvolvedor não pode ser verificado:

  1. Clique com o Botão Direito no ícone do App.
  2. Escolha Abrir no menu.
  3. Confirme clicando em Abrir na caixa de diálogo.
